# Сервис семантической сверки текстовой информации

Программная реализация сервиса для выявления семантически близких
(в том числе перефразированных) фрагментов в паре документов.
Расчёт сходства выполняется по математической модели — ансамблю
лексической, семантической и стилометрической мер.

```
S = 0,15·s_лекс + 0,55·s_сем + 0,30·s_стил
```

Пары фрагментов с оценкой S ≥ 0,75 помечаются как «Подозрение
на одинаковые формулировки».

## Как запустить

### Требования
- Python 3.9–3.12
- Доступ в интернет при первом запуске (скачивается модель Sentence-BERT, ~120 МБ)

### Способ 1. Автоматический (рекомендуется)

**Linux / macOS** — в терминале из папки проекта:
```bash
chmod +x run.sh
./run.sh
```

**Windows** — двойной клик по `run.bat`
(либо в командной строке: `run.bat`)

Скрипт сам создаст виртуальное окружение, установит зависимости
и запустит сервер.

### Способ 2. Вручную

```bash
# 1. Виртуальное окружение
python -m venv venv

# 2. Активация
#   Linux/macOS:
source venv/bin/activate
#   Windows:
venv\Scripts\activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Запуск сервера
cd backend
uvicorn main:app --port 8000
```

### Открыть сервис

После запуска откройте в браузере:

```
http://localhost:8000
```

> ВАЖНО: открывайте именно по адресу `http://localhost:8000`, а не
> двойным кликом по HTML-файлу. Иначе браузер не сможет обращаться
> к серверу (парсинг и расчёт работать не будут).

## Как пользоваться

1. **Экран 1 — Загрузка.** Перетащите или выберите два документа
   формата `.docx`: основной (эталон) и сравниваемый. Нажмите «Далее».
   Сервер разберёт документы на разделы.

2. **Экран 2 — Выбор разделов.** Отметьте разделы каждого документа,
   которые нужно сверять. Нажмите «Сравнить документы». Запустится
   расчёт сходства.

3. **Экран 3 — Результаты.** Появятся пары фрагментов с оценкой
   сходства выше порога. Кнопка «Экспорт отчёта» сохраняет результат
   в текстовый файл.

## Что происходит «под капотом»

| Этап | Что делает | Технология |
|------|------------|------------|
| 1. Парсинг | Разбор `.docx` на разделы и абзацы по стилям заголовков | python-docx |
| 2. Предобработка | Чистка, токенизация, лемматизация, удаление стоп-слов | pymorphy2 |
| 3.1. Лексическая мера | Расстояние Левенштейна по токенам | собственная реализация |
| 3.2. Семантическая мера | Косинусное сходство эмбеддингов | Sentence-BERT |
| 3.3. Стилометрическая мера | Вектор признаков стиля + гауссово ядро | numpy |
| 4. Агрегация | S = 0,15·лекс + 0,55·сем + 0,30·стил | — |
| 5. Порог | Отбор пар с S ≥ 0,75 | — |

## Настройка параметров

Веса модели и порог задаются в начале файла `backend/main.py`:

```python
ALPHA = 0.15        # вес лексической меры
BETA  = 0.55        # вес семантической меры
GAMMA = 0.30        # вес стилометрической меры
DEFAULT_TAU = 0.75  # порог сходства
```

## Возможные сложности

- **Долгий первый запуск** — при первом обращении к сверке скачивается
  модель Sentence-BERT (~120 МБ). Последующие запуски — быстрые.
- **«Не удалось связаться с сервером»** — проверьте, что бэкенд запущен
  и сервис открыт по адресу `http://localhost:8000`.
- **Документ не разбивается на разделы** — заголовки в `.docx` должны
  быть оформлены стилями «Заголовок 1/2…» (Heading). Если стилей нет,
  весь документ обрабатывается как один раздел.
- **pymorphy2 не ставится** — сервис работает и без него (лемматизация
  отключается, точность немного снижается).
